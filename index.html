📦 Installation & Usage Guide

Install via npm:

npm install unstable-text

1. Vanilla JS Zero-Config Ambient Scheduler:

import { UnstableTextScheduler } from 'unstable-text'; // Automatically scans and targets visible text in document.body const scheduler = new UnstableTextScheduler(); scheduler.start();

2. React Hook Integration (`useUnstableText`):

import React from 'react'; import { useUnstableText } from 'unstable-text/react'; export const HeroSection = () => { // Automatically handles start() on mount and destroy() on unmount const { ref, trigger } = useUnstableText({ minInterval: 800, maxInterval: 2500, neonColor: '#00ff66', glowIntensity: 'intense' }); return ( <div ref={ref}> <h1>Unstable Text System</h1> <button onClick={() => trigger('fullScramble')}>Decrypt Header</button> </div> ); };

3. Manual Trigger API:

import UnstableText from 'unstable-text'; const header = document.querySelector('h1'); UnstableText.trigger(header, 'corruptChar', { duration: 3000 });
